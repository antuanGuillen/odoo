# 8. Proyecto integrador: biblioteca del centro

## Enunciado
Desarrolla una aplicación para gestionar el préstamo de libros de una biblioteca escolar.

## Requisitos mínimos
1. Registrar libros: título, ISBN, autor, categoría y número de páginas.
2. Registrar socios: nombre, correo y teléfono.
3. Registrar préstamos: libro, socio, fecha de préstamo y fecha prevista de devolución.
4. No permitir prestar un libro que ya esté prestado.
5. Mostrar préstamos activos y devueltos.
6. Aplicar permisos distintos a bibliotecario y usuario de consulta.

## Ampliaciones
- Aviso de retrasos.
- Informe PDF de préstamos.
- Búsqueda por autor y categoría.
- Pruebas automatizadas.
- Datos demo y capturas para la memoria.

| Criterio | Peso |

| Vistas, acciones y navegación | 20 % |
| Seguridad | 20 % |
