# 1. ERP y Odoo

## ¿Qué es un ERP?
Un ERP (Enterprise Resource Planning) integra procesos de una organización en una plataforma común: ventas, compras, inventario, contabilidad, fabricación, recursos humanos, etc.

## ¿Qué aporta Odoo?
Odoo organiza la funcionalidad en aplicaciones y módulos. Los módulos pueden añadir modelos de datos, reglas de negocio, vistas, informes y automatizaciones.

## Ejemplo de proceso
Una tienda vende 3 teclados:
1. Ventas registra el pedido.
2. Inventario prepara y valida la entrega.
3. Facturación genera la factura.
4. Contabilidad registra el movimiento.

**Idea clave:** los departamentos trabajan sobre datos conectados; no mantienen hojas aisladas que se contradicen.
