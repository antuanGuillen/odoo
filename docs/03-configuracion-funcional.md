# 3. Configuración funcional

## Práctica: empresa de informática
Crea una base de datos de laboratorio y configura:
- Empresa: TecnoAula S.L.
- Moneda y zona horaria adecuadas.
- Dos usuarios: administrador y comercial.
- Un cliente: Instituto Mediterráneo.
- Dos productos: Ratón USB (18 €) y Teclado mecánico (65 €).

## Flujo de ventas
1. Crea el cliente.
2. Crea los productos y configura su política de facturación según el ejercicio.
3. Genera un presupuesto con 2 ratones y 1 teclado.
4. Confirma el pedido.
5. Revisa la entrega en Inventario.
6. Crea la factura y registra el pago solo en una base de datos de pruebas.

## Preguntas de repaso
- ¿Qué diferencia hay entre presupuesto y pedido confirmado?
- ¿Qué aplicación controla las existencias?
- ¿Por qué es importante asignar permisos por grupos y no compartir el usuario administrador?
