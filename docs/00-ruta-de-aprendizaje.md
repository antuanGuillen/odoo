# Ruta de aprendizaje

## Nivel 1 — Usuario y administrador funcional
- [ ] Entender qué problema resuelve un ERP.
- [ ] Crear una base de datos de pruebas.
- [ ] Activar modo desarrollador.
- [ ] Crear usuarios y asignar grupos.
- [ ] Configurar contactos, productos, impuestos y almacenes.
- [ ] Completar un flujo de venta: presupuesto → pedido → entrega → factura.

## Nivel 2 — Técnico
- [ ] Entender addons, manifest y dependencias.
- [ ] Crear un modelo Python.
- [ ] Añadir campos y relaciones.
- [ ] Crear vistas de lista, formulario y búsqueda.
- [ ] Definir menús y acciones.
- [ ] Configurar permisos.
- [ ] Añadir datos demo y restricciones.

## Nivel 3 — Profesional
- [ ] Campos calculados y métodos ORM.
- [ ] Herencia de modelos y vistas.
- [ ] Informes QWeb.
- [ ] Pruebas automatizadas.
- [ ] Git, ramas y despliegue controlado.

## Método para cada práctica
1. Lee el objetivo y el vocabulario.
2. Ejecuta los pasos en una base de datos de pruebas.
3. Compara el resultado con la comprobación.
4. Rompe algo deliberadamente y aprende a diagnosticarlo.
5. Completa el reto sin mirar la solución.
